# Muse-Artifacts

Web apps built with Muse, published as static snapshots so they can be opened as plain web pages.

## Apps

- [Finance Dashboard](finance-dashboard/) - accounts, spending, and cash-flow analytics (snapshot)
- [Motorcycle Gear Dashboard](motorcycle-gear-dashboard/) - riding gear kit tracker (snapshot)
- [Taiwan Trip Itinerary](taiwan-trip-itinerary/) - completed-trip archive, October 20 to November 1, 2026 (snapshot)

## Notes

- These are static exports from Muse. The live artifacts inside Muse keep their saved state and refreshes; the copies here are frozen snapshots from 2026-11-05.
- Enable GitHub Pages (Settings, Pages, deploy from the `main` branch, root folder) to serve this repo as a website.
