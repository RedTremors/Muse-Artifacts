# Muse-Artifacts

Web apps built with Muse, published as static snapshots so they can be opened as plain web pages.

## Apps

- [Job Hunt HQ](job-hunt-hq/) - application pipeline for the $90k+ job search, with the screening questions awaiting answers (snapshot, 2026-11-10)
- [Road to Riding](road-to-riding/) - motorcycle progress tracker: CMSP passed, DL 389 and DMV steps, gear status, bike hunt (snapshot, 2026-11-10)
- [Weekly Money Board](weekly-money-board/) - current-week money snapshot: paycheck split, Invest buffer, fun balance, points (snapshot, 2026-11-10)
- [Finance Dashboard](finance-dashboard/) - accounts, spending, and cash-flow analytics (snapshot)
- [Motorcycle Gear Dashboard](motorcycle-gear-dashboard/) - riding gear kit tracker (snapshot)
- [Taiwan Trip Itinerary](taiwan-trip-itinerary/) - completed-trip archive, October 20 to November 1, 2026 (snapshot)

## Notes

- These are static exports from Muse. The live artifacts inside Muse keep their saved state and refreshes; the copies here are frozen snapshots (original three from 2026-11-05; Job Hunt HQ, Road to Riding, and Weekly Money Board from 2026-11-10).
- Enable GitHub Pages (Settings, Pages, deploy from the `main` branch, root folder) to serve this repo as a website.
